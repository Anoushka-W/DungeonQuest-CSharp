# DungeonQuest-CSharp

A console-based RPG built in C# as my first project while learning the language

## About

Dungeon Quest is a small text-based RPG where the player explores different areas, encounters enemies, collects items, earns XP, and develops their character.

This project is primarily a learning project for practising C#, object-oriented programming, and software development fundamentals.

## World Map

## Planned Features

- Character creation
- Exploration and random encounters
- Combat system
- Inventory: Items and equipment
- XP and levelling
- Shop
- Boss battles
- Save and load system
